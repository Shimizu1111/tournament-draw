# 大会データ共有サーバー（Cloudflare Workers + Durable Objects）

大会データを他の端末と共有するためのサーバーです。**D1は使いません。**
大会1件につき Durable Object を1つ使い、そこにJSONを丸ごと保存します。

## 仕組み

```
ブラウザ（本部）──編集キーあり──▶ Worker ──▶ Durable Object（大会1件＝1つ）
ブラウザ（閲覧）──コードのみ────▶ Worker ──▶      〃
```

- **共有コード**（8文字）を知っていれば閲覧できます
- **編集キー**（24文字）を持つ端末だけが書き込めます
- 版番号で管理し、別の端末が先に更新していた場合は上書きせずに競合として通知します

## デプロイ

```bash
cd worker
npm install
npx wrangler login     # 初回のみ
npx wrangler deploy
```

デプロイすると `https://tournament-share.〇〇.workers.dev` のようなURLが表示されます。
このURLをアプリの「大会設定 → 他の端末と共有」に登録してください。

## 使用するリソースと無料枠

| 項目 | 無料枠 | 大会1日あたりの想定 |
|---|---|---|
| Durable Object クラス数 | 100個 | **1個** |
| オブジェクト数 | 無制限 | 大会1件につき1つ |
| リクエスト | 100,000/日 | 約11,500（6台・15秒間隔・8時間） |
| ストレージ | 5 GB | 大会1件 約50KB |
| 書き込み行数 | 100,000/日 | 数百行 |

**D1データベースは1つも作りません。**

上限を超えた場合は課金されず、操作がエラーになります（UTC 0時にリセット）。
アプリはオフラインでも動作するため、同期が止まっても大会運営そのものは継続できます。

## API

| メソッド | パス | 認証 | 内容 |
|---|---|---|---|
| POST | `/api/rooms` | なし | 共有を作成。`{code, editKey, version}` を返す |
| GET | `/api/rooms/:code` | なし | 現在の内容を取得。`{version, updatedAt, state}` |
| PUT | `/api/rooms/:code` | `X-Edit-Key` | 更新。版が古い場合は 409 とサーバー側の内容を返す |
| GET | `/health` | なし | 稼働確認 |

共有コードは大文字小文字・ハイフンの有無を問いません（`v9yy-srm7` でも `V9YYSRM7` でも可）。

## 運用メモ

- 編集キーはハッシュ化して保存しており、サーバーには平文で残りません
- 1リクエストあたりの本文は 900KB までに制限しています
- 共有を停止しても、サーバー上のデータは残ります。共有コードで再び開けます
- 作成エンドポイントは誰でも呼べます。悪用が気になる場合は Cloudflare WAF の
  レート制限を `/api/rooms` に設定してください

## 削除したいとき

```bash
npx wrangler delete
```

Worker と Durable Object のデータがすべて削除されます（元に戻せません）。
