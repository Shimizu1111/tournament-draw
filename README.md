# fantasistaカップ九州大会 抽選・組合せ運営システム

カテゴリ別の組合せ抽選から、1日目リーグ戦・2日目順位決定トーナメントの進行表作成までを
1つの画面で完結させる大会運営システムです。

**公開URL:** https://shimizu1111.github.io/tournament-draw/

ブラウザだけで動作します。入力したチーム名や試合結果がサーバーへ送信されることはありません。

---

## 大会形式

| 項目 | 内容 |
|---|---|
| カテゴリ | U-7 / U-8 / U-9（それぞれ独立して運用） |
| 参加 | 1カテゴリ 16チーム |
| コート | 1カテゴリ 2面 |
| 1日目 | 4チーム総当たりリーグ × 4ブロック ＝ 24試合 |
| 2日目 | 上位トーナメント（各ブロック1・2位）＋ 下位トーナメント（同3・4位）＝ 24試合 |
| 結果 | 1位〜16位まで全チームの順位が確定 |

### 2日目のトーナメント構成（各ブロック12試合）

```
1回戦4試合 ─┬→ 勝者4 → 準決勝2 ─┬→ 決勝        → 1位・2位
            │                     └→ 3位決定戦   → 3位・4位
            └→ 敗者4 → 5〜8位決定2 ─┬→ 5位決定戦 → 5位・6位
                                     └→ 7位決定戦 → 7位・8位
```

上位トーナメントで1〜8位、下位トーナメントで9〜16位が決まります。
1回戦は「Aブロック1位 vs Bブロック2位」のようにクロスさせ、
**同じブロック同士が当たらない**ように組んでいます。

## 主な機能

### ① 抽選
- 完全ランダム抽選。**1枠ずつ発表**できるので、LINEビデオ通話の画面共有でそのまま抽選会に使えます
- **抽選シード値**を発行。この値を記録しておけば、後から同じ抽選結果を再現して検証できます（公正性の担保）
- **同一県のチームを同じブロックに入れない**設定（任意）。県名を入力すると自動で分散配置します

### ② 組合せ・進行表
- 1日目・2日目とも、コート別・時刻入りの進行表を自動生成
- **同じチームが連続して試合しない**並びを保証（画面上でも自動チェックし表示します）
- 開始時刻・1試合の時間・インターバルを入力するだけで全試合の開始時刻を自動計算

### ③ 結果入力と自動連動
- 1日目のスコアを入力すると、勝点・得失点差・総得点・直接対決で順位を自動算出
- リーグ順位が確定すると、**2日目の対戦カードに自動でチーム名が入ります**
- 最後まで並ばない同率の場合は警告を出し、▲▼ボタンで手動確定できます
- 2日目のスコアを入力すると勝ち上がりが自動で進み、最終順位（1〜16位）が確定します
- スコアが同点の場合は「PK」ボタンで勝者を指定できます

### ④ 出力
- 印刷 / PDF保存（A4横推奨）：組合せ表・リーグ戦星取表（記入用）・進行表・トーナメント表
- CSV出力：抽選結果 / 1日目進行表 / 2日目進行表 / 最終順位
- 入力内容はブラウザに自動保存。JSONバックアップで別の端末へ引き継ぎも可能

## 使い方

1. **大会設定** — 大会名・開催日・会場・開始時刻・試合時間を入力
2. **参加チーム** — カテゴリを選び、16チームを入力（Excelからまとめて貼り付け可）
3. **抽選** — 「抽選を開始する」→「次の枠を引く」で1枠ずつ発表
4. **1日目 リーグ** — 進行表を印刷。当日はスコアを入力すると順位が自動計算されます
5. **2日目 トーナメント** — リーグ順位から対戦カードが自動生成されます
6. **印刷・出力** — 必要な資料を印刷 / CSV保存

U-7 / U-8 / U-9 は画面右上のボタンで切り替えます。**カテゴリごとに独立**しているので、
抽選も結果入力もそれぞれ別々に行えます。

> **当日の注意**：抽選が終わったら「大会設定 → バックアップを保存」を一度実行してください。
> ブラウザのデータを消した場合でも、そのファイルから復元できます。

## 技術メモ

- 素の HTML / CSS / JavaScript のみ。依存ライブラリなし
- 乱数は xmur3 ハッシュ + mulberry32 による決定的擬似乱数。シード値が同じなら必ず同じ抽選結果になります
- 抽選シード値自体は `crypto.getRandomValues()` で生成
- リーグ戦の試合順はサークル法。2ブロックを交互に割り当てることで連続試合を回避しています
