# 大会抽選システム

サッカー・フットサル等の大会向けの抽選＆組合せ作成ツールです。
ブラウザだけで動作し、入力したチーム名がサーバーへ送信されることはありません。

**公開URL:** https://shimizu1111.github.io/tournament-draw/

## 機能

- **3つの大会形式に対応**
  - トーナメント戦のみ（勝ち上がり）
  - 予選リーグ ＋ 決勝トーナメント
  - リーグ戦のみ（総当たり）
- **完全ランダム抽選** — チーム数は自由。2のべき乗でない場合も不戦勝を均等に分散配置します
- **抽選シード値** — 抽選ごとに `A7K2-XM9P-4RTQ` のような値を発行します。
  この値を「シード値を指定」欄に入力して抽選すれば、**いつでも同じ組合せを再現できます**。
  抽選会で読み上げて記録しておけば、後から結果を検証でき、公正性の証明になります
- **トーナメント表** — 試合番号付きで自動描画。当日はチーム名をクリックすると勝者が次の試合へ進みます
- **リーグ対戦カード** — サークル法による総当たり対戦順を自動生成
- **決勝トーナメント** — 「Aグループ1位 vs Bグループ2位」形式で自動作成。
  同一グループ同士が初戦で当たらないよう自動調整します
- **出力** — 印刷 / PDF保存、対戦表CSV、抽選結果CSV（Excel・Googleスプレッドシート対応）

## 使い方

1. 大会名・開催日を入力
2. 参加チームを1行に1チームずつ入力
3. 大会形式を選んで「抽選を実行する」
4. 表示された抽選シード値を記録しておく
5. 印刷 / PDF保存、またはCSVで書き出し

## ローカルで使う

`index.html` をダウンロードしてダブルクリックするだけで動きます。
外部ライブラリ・通信は一切不要なので、オフラインの会場でも使えます。

## 技術メモ

- 単一HTMLファイル（依存ライブラリなし）
- 乱数は xmur3 ハッシュ + mulberry32 による決定的擬似乱数。
  シード値が同じなら必ず同じ抽選結果になります
- 抽選シード値自体は `crypto.getRandomValues()` で生成しています
